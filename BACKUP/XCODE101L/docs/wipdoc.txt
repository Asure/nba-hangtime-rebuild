CMOS
====
Enter diagnostic mode to access the extended CMOS menus. Super max settings:

Idiot boxes: Quality of life, the game won't explain how to play, who you control, or that you should hold
the turbo buttons etc. These are disabled by default since we expect skilled players to pick this version.
You can still enable them for games on location.

Backboard shatter: Self explaining. Current code just lets you shatter forever for demo purpose.

Basketball type: The long hidden ABA ball or default ball can be selected here.

Max Rubberbanding: The Maximum Hangtime version has insane rubber banding with aggro drones. Here you
can switch between to the 'normal' Hangtime version, or MAX version of rubberbanding for a more enjoyable
or more difficult game.

Baby sized players: Normally via a code, but for easy setting and party games you can force this on.

Huge Head: Same as above. Also huge head babies are.. fun!

Show Hotspots: A new feature in MAX, each player has a hotspot, and this option shows them on the court.
(Score 3 times to perma-enable it on screen.)

Profanity: Fuck. Shit. And so on an so forth. (except, it's not in the sound code yet haha! Soon...)

New Dunks
=========
Several new dunk types added that had gfx, but were never used in order to save rom space.
Demo: You can use 'hook shots' to trigger one. (Walk down at top of bucket + turbo+shot.)

New Easter eggs
===============
Hold up+right at matchup screen to enable a MK3 easter egg on 'OUTDOOR' court.
This is polished up to have the vortex in the sky swirling (unused gfx) and an extra MK3 item near the ledge.

Hold up+left at matchup screen to enable a MK1 easter egg on 'INDOOR' court.
(Random two variants, one claps, one follows the ball.)
